1. Executive Summary & Overview

The Tourist Place Visit Planner is a full-stack, lightweight web application built specifically for travelers, backpackers, couples, and tour groups to organize travel itineraries, record visitor counts (persons), track expenses in Indian Rupees (₹ INR), and estimate comprehensive budgets in real-time.

The application is architected using procedural PHP with MySQLi prepared statements to guarantee universal compatibility with traditional LAMP/WAMP/XAMPP stacks and shared cloud hosting platforms like InfinityFree. It incorporates zero external CSS frameworks, rendering via a custom responsive design system with cards, stats grids, and styled tables.

2. Key Functional Features

🔐 User Authentication System

Registration and login with uniqueness checks, Bcrypt hashing (PASSWORD_DEFAULT), password_verify(), and session fixation defense via session_regenerate_id().

👥 Travellers & Group Sizing

Stores the exact number of persons per journey, auto-calculates per-person expenditure (₹Budget / Persons), and shows total travelers planned.

🧮 Interactive Budget Estimator

Real-time calculation engine (both on add_trip.php and standalone estimator.php) computing itemized breakdowns for Stay (40%), Food (25%), Transport (20%), and Activities (15%).

🔍 Destination Search Filter

Real-time destination search on the dashboard using SQL prepared statements (WHERE user_id = ? AND destination LIKE ?) with clear-filter shortcuts.

🛡️ Multi-Layer Security Architecture

100% prepared statements across all queries, complete XSS escaping via htmlspecialchars(), user data isolation, and friendly error suppression.

⚡ Automatic Dual-Environment Support

db.php detects whether it is running on localhost or InfinityFree production, switching credentials dynamically without configuration breakage.

3. Database Schema & Architecture (MySQL)

The relational schema enforces data integrity through foreign keys with ON DELETE CASCADE so that removing an account automatically purges associated itineraries.

Table: users

Field Type Null / Key Description
id INT AUTO_INCREMENT PRIMARY KEY Unique user identifier.
username VARCHAR(50) UNIQUE, NOT NULL Unique username for login authentication.
email VARCHAR(100) UNIQUE, NOT NULL Unique user email address.
password VARCHAR(255) NOT NULL Secure Bcrypt hashed password string.
created_at TIMESTAMP DEFAULT CURRENT Account creation timestamp.

Table: trips

Field Type Null / Key Description
id INT AUTO_INCREMENT PRIMARY KEY Unique trip plan record identifier.
user_id INT FOREIGN KEY Links to users(id) with ON DELETE CASCADE.
destination VARCHAR(100) NOT NULL Tourist destination, landmark, or city name.
travel_date DATE NOT NULL Scheduled departure date.
persons INT NOT NULL, DEF 1 Number of travellers participating in the visit.
budget DECIMAL(10,2) NOT NULL Total estimated trip budget in Indian Rupees (₹ INR).
visitor_email VARCHAR(100) NOT NULL Visitor contact email for itinerary notifications.
notes TEXT NULL Custom itinerary highlights, bookings, and reminders.
created_at TIMESTAMP DEFAULT CURRENT Record creation timestamp.

6. Interactive Trip Budget Estimator Specifications

The budget estimator calculates realistic costs based on duration, traveller count, geographical scope, and travel tiers:

  • 🎒 Budget / Backpacker Tier: ~₹2,500/day/person (Domestic) | ~₹6,500/day/person (International)
  • 🏨 Comfort / Standard Tier: ~₹5,500/day/person (Domestic) | ~₹13,500/day/person (International)
  • 👑 Luxury / Premium Tier: ~₹14,000/day/person (Domestic) | ~₹32,000/day/person (International)

Itemized Component Breakdown Formula:

  • 🏨 Accommodation & Stay: 40% of total estimated budget
  • 🍽️ Food & Dining: 25% of total estimated budget
  • 🚕 Local Transport & Transit: 20% of total estimated budget
  • 🎟️ Activities, Sightseeing & Buffer: 15% of total estimated budget
